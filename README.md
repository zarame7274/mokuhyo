# 売上目標トラッカー

月間目標（単価 × 目標本数）に対して毎日の売上を入力すると、残りの日の目標が自動で計算し直されるWebアプリです。スタッフ全員が同じデータを見て入力できます。

- 画面：GitHub Pages（`index.html` / `app.js` / `style.css` / `config.js`）
- データ：Googleスプレッドシート（`sheet/売上目標トラッカー.xlsx` を取り込んだもの）
- 中継役：Google Apps Script（`apps-script/Code.gs`）

## 目標の計算方法

```
残り1日あたり目標 = (月間目標 − 累計売上) ÷ 残り営業日の重みの合計 × その日の重み
```

- 曜日ごとに「重み」を設定できます（土日1.5なら、平日の1.5倍の目標になります）
- 休業日にした日は重み0として配分から外れます
- 売上を入力済みの日は「その日の朝の時点の目標」を表示するので、差額で日ごとの良し悪しがわかります

## セットアップ（最初の1回だけ）

### 1. スプレッドシートを用意する
1. `sheet/売上目標トラッカー.xlsx` をGoogleドライブにアップロードします
2. 右クリック →「アプリで開く」→「Googleスプレッドシート」を選びます
3. 開いたら「ファイル」→「Googleスプレッドシートとして保存」を選びます（Apps Scriptを使うために必要です）

### 2. Apps Scriptを公開する
1. スプレッドシートのメニューで「拡張機能」→「Apps Script」を開きます
2. 最初からある `コード.gs` の中身をすべて消し、`apps-script/Code.gs` の中身を貼り付けて保存します
3. 右上の「デプロイ」→「新しいデプロイ」を押します
4. 歯車アイコンで「ウェブアプリ」を選び、次のように設定します
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
5. 「デプロイ」を押し、Googleアカウントへのアクセスを許可します（「安全ではないページ」と出たら「詳細」→「（プロジェクト名）に移動」）
6. 表示された **ウェブアプリのURL**（`https://script.google.com/macros/s/.../exec`）をコピーします

> **パスコード（おすすめ）**：URLを知っている人は誰でも書き込めるので、Apps Scriptの「プロジェクトの設定」→「スクリプト プロパティ」に `PASSCODE` という名前で合言葉を追加しておくと安心です。スタッフはアプリの「設定」→「パスコード」で一度入力すれば、その端末では記憶されます。

### 3. 画面にURLを設定して公開する
1. `config.js` の `API_URL` にコピーしたURLを貼り付けて、GitHubに反映します
2. GitHubのリポジトリの「Settings」→「Pages」で、Branchを `main`、フォルダを `/ (root)` にして保存します
3. 数分後に表示されるURL（`https://ユーザー名.github.io/リポジトリ名/`）をスタッフに共有します

## 使い方
- **売上を入力**：日付を選んで金額を入れ、「保存」を押します。表の行をタップしてもその日を選べます
- **休業日**：表の「休」にチェックを入れます
- **単価・目標本数・曜日の重み**：画面下の「設定」から変更します
- **月の切り替え**：「設定」→「新しい月を始める」。今月の表はスプレッドシートに `2026-11` のような名前のシートとして残ります

`config.js` が空のままだと **デモモード**（入力はその端末だけに保存）で動くので、`index.html` をブラウザで開けばすぐに試せます。

## 注意
- Apps Scriptのコードを変更したら、「デプロイ」→「デプロイを管理」→ 編集 →「新バージョン」で再デプロイしないと反映されません
- スプレッドシートの「売上目標」シートの行や列の位置は、Apps Scriptが前提にしています。列を追加したいときは `tools/make_sheet.py` と `apps-script/Code.gs` を一緒に直してください
