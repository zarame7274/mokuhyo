# 売上目標トラッカー

月間の **目標売上** と **目標本数** に対して毎日の実績を入力すると、残りの日の目標が自動で計算し直されるWebアプリです。スタッフ全員が同じデータを見て入力できます。

- 画面：GitHub Pages（`index.html` / `app.js` / `style.css` / `config.js`）
- データ：Googleスプレッドシート
- 中継役：Google Apps Script（`apps-script/Code.gs`）。シートのレイアウトもここで作ります

## 目標の計算方法

売上と本数は、それぞれ別々に同じ方法で計算します。

```
残り1日あたり目標 = (月間目標 − 累計実績) ÷ 残り営業日の重みの合計 × その日の重み
```

- **残り営業日** = 今日以降で、まだ実績を入力していない日。過去の未入力日は0として扱います（入れ忘れで目標が甘くならないように）。あとから入力すれば反映されます
- 曜日ごとに「重み」を設定できます（土日1.5なら、平日の1.5倍の目標になります）
- 休業日にした日は重み0として配分から外れます
- 実績を入力済みの日と過ぎた日は「その日の朝の時点の目標」を表示するので、差額で日ごとの良し悪しがわかります

## セットアップ（最初の1回だけ）

### 1. スプレッドシートとApps Scriptを用意する
1. Googleドライブで新しいスプレッドシートを作ります
2. メニューの「拡張機能」→「Apps Script」を開きます
3. 最初からある `コード.gs` の中身をすべて消し、`apps-script/Code.gs` の中身を貼り付けて保存します
4. スプレッドシートのタブに戻って再読み込みすると、メニューに「**売上目標**」が出ます
5. 「売上目標」→「**シートを作成・更新**」を実行します（初回はGoogleアカウントへのアクセスの許可を求められます）

### 2. パスコードを設定する（必須）
1. Apps Scriptの左側の歯車「プロジェクトの設定」を開きます
2. 一番下の「スクリプト プロパティを追加」で、プロパティを `PASSCODE`、値を合言葉にして保存します
   - 設定しないと、アプリは何も表示しません（売上を誰にも見られないようにするためです）
   - 推測されにくい8文字以上にしてください

### 3. ウェブアプリとして公開する
1. Apps Scriptの右上の「デプロイ」→「新しいデプロイ」を押します
2. 歯車アイコンで「ウェブアプリ」を選び、実行するユーザーを「**自分**」、アクセスできるユーザーを「**全員**」にします
3. 「デプロイ」を押し、表示された **ウェブアプリのURL** をコピーします

### 4. 画面にURLを設定して公開する
1. `config.js` の `API_URL` にURLを貼り付けて、GitHubに反映します
2. GitHubの「Settings」→「Pages」で、Branchを `main`、フォルダを `/ (root)` にして保存します
3. 表示されたURL（`https://ユーザー名.github.io/リポジトリ名/`）と、パスコードをスタッフに伝えます

> 画面（GitHub Pages）は誰でも開けますが、パスコードを知らない人には売上も設定も表示されません。データはGoogleスプレッドシートにだけあり、GitHubには置かれません。

## Code.gs を更新したとき
1. Apps Scriptのコードを最新の `apps-script/Code.gs` に置き換えて保存します
2. 「デプロイ」→「デプロイを管理」→ 鉛筆アイコン →「バージョン」で「**新バージョン**」を選び、「デプロイ」を押します（URLは変わりません）
3. シートのレイアウトが変わった場合は、スプレッドシートで「売上目標」→「シートを作成・更新」を実行します。入力済みの売上・本数・設定・休業日は引き継がれます

## 使い方
- **実績を入力**：日付を選んで売上金額と本数を入れ、「保存」を押します。片方だけでも保存できます。表の行をタップしてもその日を選べます
- **休業日**：表の「休」にチェックを入れます
- **月間目標売上・月間目標本数・曜日の重み**：画面下の「設定」から変更します
- **月の切り替え**：「設定」→「新しい月を始める」。今月の表はスプレッドシートに `2026-11` のような名前のシートとして残ります

`config.js` が空のままだと **デモモード**（入力はその端末だけに保存、パスコード不要）で動くので、`index.html` をブラウザで開けばすぐに試せます。
